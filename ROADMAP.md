# Развитие «Рядом»

Это порядок работы, а не обещанные даты и не список уже завершённых функций.

| Этап | Результат |
| --- | --- |
| Публичная разработка | Чистые исходники, понятная главная страница, Issues, воспроизводимая Windows-сборка |
| Подготовка подписи | Проверка зависимостей, GitHub CI, собственное уведомление в установщике, заявка SignPath |
| Сеть для публичной версии | P2P первым, собственный TURN владельца; общий резерв только через защищённую выдачу с квотами |
| Проверяемая бета | Матрица Windows 10/11, разные сети, отказ UAC, обновление и миграция настроек, перезагрузка |
| Первый стабильный выпуск | Подписанные Portable/Setup, соответствующие исходники, хеши, подтверждённая инструкция |

Сейчас приложение испытывается владельцем и родственниками. Публичный полный
аудит, CI из нового форка и все проверки стабильного выпуска пока не пройдены.

Помочь можно отчётами об ошибках, проверкой на своих устройствах, улучшением
инструкций и небольшими PR. Детали: [CONTRIBUTING.md](CONTRIBUTING.md).
