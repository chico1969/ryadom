# Рядом

Открытое приложение удалённой помощи для Windows на основе RustDesk 1.5.3.

**Идёт разработка; тестовые Windows EXE находятся в `dist/development`.** Служба поиска
на alwaysdata проверена владельцем без VPN. Установка, обновление и перезапуск
службы на ПК разработки прошли; текущая версия ожидает проверки на втором ПК. Сделанное, ограничения и
инструкции сборки: [ryadom/README_RU.md](ryadom/README_RU.md).

## Code signing policy

Текущие тестовые EXE не подписаны. Подготовка заявки в SignPath Foundation
не означает одобрение или спонсорство: [правила подписи](CODE_SIGNING.md),
[конфиденциальность](PRIVACY.md), [шаги для владельца](ryadom/signing/README_RU.md).
