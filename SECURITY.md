# Безопасность «Рядом»

Проект находится в разработке. Независимый аудит всего приложения ещё не
завершён. Наличие цифровой подписи в будущем не будет означать отсутствие ошибок.

## Сообщить об уязвимости

В [официальном репозитории «Рядом»](https://github.com/chico1969/ryadom/security)
откройте **Security → Report a vulnerability** — приватные отчёты включены.
Если кнопки нет, сначала откройте Issue только с
просьбой предоставить приватный канал связи — без деталей уязвимости, паролей,
ключей, данных пользователей и инструкции атаки. Не отправляйте сообщения
пользователям RustDesk от имени этого форка.

В приватном отчёте укажите затронутую сборку, минимальное воспроизведение,
последствия и проверенные условия. Срок ответа и bug bounty пока не обещаются.
Обсудите публичное раскрытие с владельцем до публикации технических деталей.

## Границы доступа

ID не разрешает управление. Разовый доступ подтверждает владелец удалённого ПК;
постоянный доступ настраивается отдельно. Не принимайте запросы незнакомых людей.
Удалённый терминал, файлы и административные действия требуют тех же разрешений.
Программа не обходит пароль администратора или ограничения Windows.

Публичный исходный код не содержит семейных TURN-паролей, ключей хостинга или
подписи. Временные TURN-данные всё равно видны использующему их клиенту: защита
строится на сроке действия, разрешениях и квотах сервера, а не на обфускации EXE.

См. [конфиденциальность](PRIVACY.md), [Code signing policy](CODE_SIGNING.md) и
[сетевую модель](ryadom/NETWORK_SECURITY_RU.md).
