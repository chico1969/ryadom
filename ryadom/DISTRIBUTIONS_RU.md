# Сборки «Рядом»

| Комплект | TURN | Куда передавать |
| --- | --- | --- |
| Публичный | Готовых личных TURN-настроек нет | GitHub, другим пользователям, принимающему ноутбуку для проверки |
| Семейный | Резерв владельца предварительно настроен | Владельцу и его знакомым; отдельно от публичных файлов |

В обоих комплектах есть `Ryadom.exe` для запуска без установки и
`Ryadom-Setup.exe` для установки службы Windows. Режим закреплён в EXE:
переименование, в том числе добавление браузером `(1)`, его не меняет.
Явные аргументы командной строки обрабатываются отдельно.

Setup сначала показывает окно установки. Запрос Windows с правами администратора
появляется после нажатия кнопки установки. Файлы установщика распаковываются в
отдельную временную папку, чтобы работающий Portable не удерживал старые DLL.
Временные папки `ryadom-install-*` не удаляются, пока окно установки использует их;
отдельная фоновая очистка в этой версии не добавлена.

Установка сохраняет прежние ID, постоянный пароль и настройки. Если приём ранее
выключен, на главном экране есть «Включить приём». Включение требует явного
нажатия владельца; это штатное действие запуска службы, доступное и в общих
настройках. На новом ПК установка службы требует прав администратора.

Выключенный приём не требует существующей службы для завершения Setup: выбор
автозапуска сохраняется и применяется после явного включения приёма. При переносе
защищённого ключа он открывается в исходном профиле перед защитой для службы.
Сообщения установщика различают этапы ошибок `9060`–`9064`; прежний общий код
`9059` больше не используется для этих операций.

Шестерёнка открывает все настройки приложения. Подписанная кнопка «P2P / TURN»
открывает настройки подключения. Светлая и тёмная темы используют отдельные
контрастные цвета фона, карточек, текста и элементов управления.

## Публичная сборка

Рекомендуемый Windows-процесс: `ryadom/build-windows.ps1` без `-BundleTestTurn`.
Он собирает Portable и отдельный Setup с feature `ryadom-setup`, проверяя оба
режима. Обычный запуск Cargo для упаковщика создаёт Portable, даже если затем
файл назовут `install.exe`.

Настройки службы поиска уже заданы. Для прямого соединения пользователю не нужно
вводить адрес сервера. Собственный TURN можно настроить на помогающем ПК через
«P2P / TURN»; принимающая сторона может использовать его relay-кандидат без
получения TURN-пароля. Возможность такого соединения зависит от сетей обоих ПК.
Проверка рабочего стола между двумя разными сетями выполняется отдельно от
локального транспортного теста.

## Семейная сборка

`ryadom/build-windows.ps1 -BundleTestTurn` использует локальный игнорируемый файл
`.tools/turn.express.local.json`. Он не входит в исходники и публичный комплект.
Такой EXE предназначен для круга владельца: предварительная конфигурация доступна
запускающей программе и не является серверным хранилищем секретов.

Публиковать следует только проверенные публичные EXE, исходники, лицензию и
контрольные суммы. Семейные бинарники хранятся отдельно. Тестовые сборки пока
не имеют цифровой подписи; готовность SignPath не заявляется.
