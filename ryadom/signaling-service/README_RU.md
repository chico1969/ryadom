# Служба согласования «Рядом»

Workers Free, SQLite Durable Object, без постоянных записей базы. Публичный
адрес берётся из `../signaling.json`. Регистрация ID и обмен SDP/ICE используют
малую совместимую часть PeerServer WebSocket-протокола; HBBS/HBBR здесь нет.
Сервис не принимает экран, файлы, пароль доступа, терминал или звук от клиента
Рядом. Данные сеанса продолжают идти по DTLS WebRTC между устройствами или TURN.

```powershell
npm ci
npm run dev
```

В другом терминале `npm test` проверяет локальную службу. Для явной проверки
опубликованного узла задайте `RYADOM_SIGNAL_TEST_URL=wss://имя/peerjs`.
Тесты создают только временные собственные подключения и затем закрывают их.

Публикация владельцем: `npm run deploy` после авторизации официального Wrangler.
Используются Account Read, User Read, Workers Scripts Write и Background Access.
Авторизация хранится локально; она не относится к публичному ключу приложения
и не должна попадать в EXE, web, исходный архив или git. Для этой рабочей копии
`XDG_CONFIG_HOME` направлен в игнорируемую `../../.tools/cloudflare`.
Доступ можно отозвать в Cloudflare → My Profile → Connected Applications.

При повторении в другом аккаунте используйте Workers Free и SQLite-backed
namespace; подключение карты и платный план не требуются выбранной конфигурации.
При исчерпании лимитов Free операции прекращаются с ошибкой.

Узел ограничен 128 соединениями, сообщения — 128 КиБ, 80 сообщений/с и 512 КиБ/с
на сокет. Сигнальные имена публичны, их владение не считается авторизацией ПК.
Публичного списка устройств нет. Реестр возвращает ID-TAKEN для занятого имени;
при отсутствии heartbeat более 30 секунд прежняя регистрация освобождается при
следующем обращении. Сервер принудительно подставляет настоящий `src` соединения.
Обработка heartbeat использует auto-response, чтобы не будить Durable Object.
Функции логирования запросов/содержимого отключены в конфигурации Wrangler.
Эти ограничения не обеспечивают защиту от намеренного истощения бесплатной квоты.

14.11.2026 проверены локальное и опубликованное развёртывания, Rust/Windows WS
и браузерный WebRTC-стенд. Пользователь подтвердил доступ к `/health` на втором
ПК только через VPN. Работу без VPN в этой сети сервис пока не обеспечивает.

Условия: [Cloudflare Durable Objects Free](https://developers.cloudflare.com/durable-objects/platform/pricing/),
[WebSocket Hibernation](https://developers.cloudflare.com/durable-objects/best-practices/websockets/).
